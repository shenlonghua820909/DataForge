# DataForge · 数据建模平台 — 设计规范文档

> **对标对象**：阿里云 DataWorks + 字节火山引擎 DataLeap + OneData 方法论
> **设计原则**：专业 · 清晰 · 高效 · 一致
> **交付物**：14 个高保真页面 + 共享设计系统

---

## 一、设计哲学

### 1.1 三大核心原则

| 原则 | 解释 | 落地手段 |
|------|------|---------|
| **业务语义优先** | 不只是表结构，更是业务语义的沉淀 | 业务口径 vs 技术口径分离；维度/事实/指标业务命名 |
| **闭环可视化** | 建模全流程可看、可追溯、可理解 | 血缘图、版本对比、关系图、状态机 |
| **专业感与温度并存** | 像 IDE 一样专业，但有人情味 | 精致排版、留白、便签提示、AI 智能助手 |

### 1.2 五大信息架构原则

1. **层级清晰**：顶部全局菜单 + 二级 Tab + 三栏布局
2. **目录前置**：左侧目录树永远可见，避免"迷路"
3. **详情右置**：右侧抽屉式详情，不打断主流程
4. **操作集中**：编辑、发布、删除等主操作永远在右上角
5. **状态外显**：版本、负责人、最近修改、状态徽章常驻

## 二、设计 Token 系统

### 2.1 品牌色（Brand · Data Blue）

```
--brand-50:  #EEF4FF
--brand-100: #D9E5FF
--brand-300: #8AABFF
--brand-500: #1E66F5   ← 主色，CTA、链接、激活状态
--brand-600: #1651D4
--brand-700: #103FA8
--brand-900: #081F55
```

> **灵感来源**：阿里云蓝 + 火山引擎蓝 + 字节主品牌的现代企业感

### 2.2 数仓分层色（关键约定）

| 分层 | 颜色 | 含义 |
|------|------|------|
| **ODS** 原始数据层 | `#8AABFF` 蓝紫 | 原始数据、保持原貌 |
| **DWD** 明细层 | `#1E66F5` 品牌蓝 | 业务过程事实 + 宽表 + 维度/主档 |
| **DWT** 主题汇总层 | `#F59E0B` 琥珀 | 跨域多表关联后单独生成的汇总 |
| **ADS** 应用层 | `#E5484D` 砖红 | 业务场景、面向应用 |

> **口径约定（四层）**：本原型采用 `ODS / DWD / DWT / ADS` 四层口径。
> 原「DIM 维度层」已并入 **DWD 明细层**，维度表与主档表统一使用 `dwd_` 前缀；
> 原「DWS 汇总层」更名为 **DWT 主题汇总层**，前缀 `dwt_`。
> 「维度建模（Dimensional Modeling）」作为建模方法论保留，与分层口径互相正交。

### 2.3 模型实体色

| 实体类型 | 颜色 | 示例 |
|---------|------|------|
| 概念-维度 | `#5BC0BE` 青绿 | 时间、地域 |
| 维度/主档表 | `#18A957` 绿 | dwd_patron, dwd_bib（归属 DWD 层） |
| 明细表 | `#1E66F5` 蓝 | dwd_trade_order |
| 主题汇总表 | `#F59E0B` 橙 | dwt_gmv_daily |
| 应用表 | `#E5484D` 红 | ads_user_profile |

### 2.4 语义色

- 成功 `#18A957` · 已发布、健康
- 警告 `#F59E0B` · 审批中、待关注
- 错误 `#E5484D` · 失败、超时、删除
- 信息 `#0EA5E9` · 提示、链接

## 五、关键交互模式

### 5.1 三栏布局（最高频）

```
┌─────────┬───────────────────────┬──────────┐
│  Tree   │  Content (List/Table) │  Detail  │
│  260px  │      flex 1            │  380px   │
└─────────┴───────────────────────┴──────────┘
```

**适用场景**：
- 维度建模（树=模型目录，列表=模型，详情=属性）
- 关系图（树=待添加，详情=节点属性）
- 血缘图（树=过滤条件，详情=血缘关系）

### 5.2 画布交互（核心差异化）

```
[Top Toolbar]  ← 顶部悬浮工具栏（V/H/T/N/L/G/↶/↷）
[Left Panel]   ← 待添加模型列表
[Canvas]       ← 画布区域（网格 + 模型节点 + 连线）
[Right Panel]  ← 选中节点属性
[Bottom Bar]   ← 缩放控制 + 画布信息
```

**交互细节**：
- 拖拽：左侧模型 → 画布
- 连线：工具栏 L → 拖拽连接节点 → 双击连线添加描述
- 工具栏：选择 / 移动 / 文字 / 便签 / 连线 / 分组 / 撤销 / 重做
- 画布操作：滚轮缩放 / 空白拖动 / Ctrl+Z 撤销

### 5.3 版本对比

```
左版本（红色标识）  →  →  右版本（绿色标识）
       ↓                  ↓
   字段名、类型、关联、DDL 差异
       ↓
  颜色编码: +绿 -红 ~黄 未变灰
```

### 5.4 步骤式流程

发布 / 逆向建模 / 新建表 等关键流程统一采用 4 步引导：
1. 选源 / 选分层
2. 智能分析 / 基本信息
3. 确认映射 / 字段配置
4. 生成 / 关联发布

## 六、关键业务概念呈现

### 6.1 OneData 指标体系

**三层指标架构**：

```
原子指标 (A)  ←  不可再拆解 · 度量 + 业务过程
   ↓ + 时间周期 + 修饰词 + 维度
派生指标 (⚡)  ←  业务常用 · 标准化口径
   ↓ + 多派生运算
衍生指标 (%)  ←  比率/比例/差值
```

**视觉化**：用不同颜色徽章（蓝/橙/绿）+ 不同图标（A/⚡/%）区分

### 6.2 数仓分层架构

```
┌────────────────────────────────────────────┐
│  ADS · 应用层  (数据服务/BI)                │  ← 面向业务
├────────────────────────────────────────────┤
│  DWT · 主题汇总层  (跨域多表关联汇总)         │
├────────────────────────────────────────────┤
│  DWD · 明细层  (业务过程 + 宽表 + 维度主档)   │  ← 核心建模
├────────────────────────────────────────────┤
│  ODS · 原始数据层  (原始数据)                │  ← 保持原貌
└────────────────────────────────────────────┘
```

### 6.3 维度建模

**三种事实表**：
- 事务事实表：每笔业务事件
- 周期快照：固定时间间隔的状态
- 累积快照：业务全生命周期的多个时间点

**四步法**：选业务过程 → 声明粒度 → 确认维度 → 确定事实
